```
Google Gemini gives you great answers in a cramped, unstyled column. This free
Chrome extension fixes the reading experience — and renders Mermaid diagrams
right next to their source.

Install: https://chromewebstore.google.com/detail/ajboihpfgkpcpeibiahobpdogdbbmfpn

WHAT IT DOES

• Typography — set font size, line height, paragraph spacing and column width.
  Gemini ships none of these controls.
• Six colour schemes — Solarized, Nord, Gruvbox, Amber, Sepia, plus a true
  pass-through that emits no colour rules at all. Each ships a matched light and
  dark palette and follows Gemini's own theme switch.
• Mermaid diagrams — flowchart, sequence, mindmap, ER, class, state and gantt
  render beside their source. Pan, zoom, auto-fit, fullscreen, export SVG, or
  copy as a 2x PNG.
• Copy as Markdown — one button in Gemini's own action row copies an answer as
  clean Markdown, headings and code fences intact.

Settings apply instantly — no reload, no save button. Available in English,
简体中文, 繁體中文, 日本語, हिन्दी, Deutsch and Français.

Open source: https://github.com/Deguang/gemini-graph-viewer

#GoogleGemini #ChromeExtension #Mermaid #ProductivityTools
```
